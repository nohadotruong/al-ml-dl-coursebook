Data cleaning / preprocessing:
1. Drop – Delete unnecessary or unclean columns or rows:
   - Column has a high percentage of missing values
   - Column does not affect the problem

    df = df.drop(['PassengerId', 'Cabin'], axis=1)
    df = df.drop_duplicates()

2. Impute – Fill missing values for important columns:
   - Numerical: median, mean, or predict using a model
   - Categorical: mode (most frequent value)

   # Age numeric
    df['Age'] = df['Age'].fillna(df['Age'].median())

    # Embarked categorical
    df['Embarked'] = df['Embarked'].fillna(df['Embarked'].mode()[0])

3. Scale – Standardize values to a common range:
   - StandardScaler (z-score): (x - mean) / std → mean 0, std 1
   - MinMaxScaler: scale values to 0–1

    from sklearn.preprocessing import StandardScaler
    scaler = StandardScaler()
    df['Age_scaled'] = scaler.fit_transform(df[['Age']])

4. Encode – Convert categorical features to numerical:
   - OneHotEncoder: create a column for each category
   - LabelEncoder: assign 0,1,2… for categories (useful for tree-based models)

    from sklearn.preprocessing import OneHotEncoder, LabelEncoder

    # LabelEncoder
    le = LabelEncoder()
    df['Sex_encoded'] = le.fit_transform(df['Sex'])

    # OneHotEncoder
    ohe = OneHotEncoder(sparse=False)
    sex_ohe = ohe.fit_transform(df[['Sex']])
